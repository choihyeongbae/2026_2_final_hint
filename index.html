배열

모든 단원의 기본이에요. 인덱스와 range의 "끝은 포함 안 됨" 규칙을 확실히 잡고 가세요.

배열은 변수 하나에 여러 개의 값을 담는 자료구조예요. 대괄호 [ ]로 만들고, 안에 든 값 하나하나를 원소라고 불러요.

1-4. 반복문과 배열: range의 규칙

range(시작, 끝, 간격)은 시작부터 끝 바로 앞까지 간격만큼 건너뛰며 숫자를 만들어요. 끝 숫자는 포함되지 않아요.

코드만들어지는 숫자개수
range(5)0, 1, 2, 3, 45개
range(3, 7)3, 4, 5, 64개
range(1, 10, 3)1, 4, 73개
range(10, 0, -2)10, 8, 6, 4, 25개
코드
c = []
for i in range(1, 6):
    c.append(i * 10)    # 반복할 때마다 맨 뒤에 추가
print(c)

# 뒤에서부터 거꾸로 출력하기: -1, -2, ..., -len(c)
for i in range(-1, -len(c)-1, -1):
    print(c[i], end=" ")
실행 결과
[10, 20, 30, 40, 50]
50 40 30 20 10
💡 거꾸로 출력 코드 읽는 법

range(-1, -len(c)-1, -1)에서 len(c)가 5이면 range(-1, -6, -1) → -1, -2, -3, -4, -5예요. 끝 값 -6은 포함되지 않으니 딱 5번 반복해요.

코드
# 입력받아 배열 만들기 (코랩에서는 실행하면 입력 칸이 나와요)
a = []

2-1. 슬라이싱 vs 인덱스 호출

겉보기엔 비슷해도 결과의 자료형이 달라요. 슬라이싱 결과는 원소가 1개뿐이어도 항상 배열이고, 인덱스 호출은 원소 하나예요.

코드
s = [10, 20, 30, 40, 50, 60, 70, 80]
print(s[3:4], s[3])
print(type(s[3:4]))
print(type(s[3]))
실행 결과
[40] 40
<class 'list'>
<class 'int'>
🔑 핵심 정리
  • s[3] → 원소 40
  • s[3:4] → 배열 [40] (대괄호가 붙어서 출력됨)
  • 간격이 음수이면 시작 번호가 끝 번호보다 커야 원소가 나와요. 아니면 빈 배열 []이에요.

딕셔너리

키로 값을 찾는 구조를 이해하면 데이터프레임도 쉬워져요.

🆕 수업 시간에 짧게 지나간 부분이라 꼭 읽어 보세요!

딕셔너리에서 값을 꺼내는 방법은 시험에 나올 수 있는 내용이에요. 천천히 따라오세요.

3-1. 딕셔너리란?

딕셔너리는 키(key)와 값(value)이 짝을 이뤄 저장되는 자료구조예요. 중괄호 { }로 만들고, 키 : 값 형태로 적어요. 사전에서 단어(키)를 찾으면 뜻(값)이 나오는 것과 같아요.

코드
pet = {"이름": "보리", "나이": 3, "종류": "고양이"}
print(pet)
실행 결과
{'이름': '보리', '나이': 3, '종류': '고양이'}

3-2. 값 꺼내기: 번호가 아니라 키로!

배열은 배열[번호]로 꺼내지만, 딕셔너리는 딕셔너리[키]로 꺼내요. 키가 문자열이면 따옴표까지 정확히 써야 해요.

코드
pet = {"이름": "보리", "나이": 3, "종류": "고양이"}
print(pet["이름"])
print(pet["나이"] + 1)
실행 결과
보리
4
⚠️ 이렇게 쓰면 오류
  • pet[0] → 오류(KeyError). 딕셔너리에는 0이라는 키가 없어요.
  • pet["색깔"] → 오류(KeyError). 없는 키를 찾으면 오류가 나요.
  • pet[이름] → 오류(NameError). 따옴표가 없으면 변수 이름으로 읽어요.

3-3. 값이 배열일 때: 딕셔너리[키][번호]

데이터 분석에서는 값 자리에 배열이 들어간 딕셔너리를 많이 써요. 이때는 두 단계로 꺼내요. ① 키로 배열을 꺼내고 → ② 그 배열에서 인덱스로 원소를 꺼내요.

코드
club = {
    "이름": ["민지", "서연", "하은", "지우"],
    "학년": [1, 2, 1, 2],
    "점수": [88, 92, 75, 81]
}
print(club["점수"])       # ① 키로 배열 꺼내기
print(club["점수"][2])    # ② 그 배열의 인덱스 2
print(club["이름"][-1])   # 이름 배열의 마지막 원소
실행 결과
[88, 92, 75, 81]
75
지우
🔑 읽는 순서

club["점수"][2]는 왼쪽부터 읽어요. club["점수"] = [88, 92, 75, 81] → 그다음 [2] → 앞에서 세 번째인 75. 인덱스는 0부터라는 것, 잊지 마세요!

3-4. 딕셔너리 → 데이터프레임

값이 배열인 딕셔너리를 pd.DataFrame()에 넣으면 키는 열 이름, 배열은 그 열의 데이터가 돼요. 그래서 데이터프레임에서 df["점수"]로 열을 꺼내는 방식이 딕셔너리와 똑같아요.

코드
import pandas as pd
df = pd.DataFrame(club)

넘파이와 그래프

같은 기호라도 일반 배열과 넘파이 배열은 결과가 달라요. 그래프 함수는 표로 한 번에 정리해 두세요.

4-1. 일반 배열 vs 넘파이 배열

넘파이(numpy)는 숫자 계산을 빠르게 해 주는 라이브러리예요. 같은 +, *라도 일반 배열과 넘파이 배열은 하는 일이 완전히 달라요.

코드
import numpy as np
a = [1, 2, 3]            # 일반 배열
b = np.array([1, 2, 3])  # 넘파이 배열
print(a + a)
print(b + b)
print(a * 3)
print(b * 3)
실행 결과
[1, 2, 3, 1, 2, 3]
[2 4 6]
[1, 2, 3, 1, 2, 3, 1, 2, 3]
[3 6 9]
연산일반 배열넘파이 배열
+두 배열을 이어 붙임같은 자리 원소끼리 더함
* 정수배열을 그 횟수만큼 반복각 원소에 곱함
출력 모양쉼표 있음 [1, 2, 3]쉼표 없음 [1 2 3]

4-2. np.arange

np.arange(시작, 끝, 간격)은 range처럼 숫자를 만들되 넘파이 배열로 만들어요. 역시 끝 값은 포함되지 않고, range와 달리 0.5 같은 소수 간격도 쓸 수 있어요.

코드
print(np.arange(5))
print(np.arange(2, 10, 3))
print(np.arange(0, 2, 0.5))
year = np.arange(2020, 2024)
print(year, len(year))
실행 결과
[0 1 2 3 4]
[2 5 8]
[0.  0.5 1.  1.5]
[2020 2021 2022 2023] 4

4-3. 함수 그래프 그리기

촘촘한 x값을 np.arange로 만들고, 넘파이 배열의 계산을 이용해 y값을 한 번에 구한 뒤 plt.plot(x, y)로 그려요. 거듭제곱은 **로 써요.

코드
import matplotlib.pyplot as plt
x = np.arange(-3, 3, 0.01)   # -3부터 3 직전까지 0.01 간격
y = x**3 - 3*x               # 넘파이 배열이라 모든 x에 대해 한 번에 계산
plt.plot(x, y, c="salmon")
plt.grid()
plt.show()
💡 그래프 모양 읽는 법
  • x**2는 U자 모양, x**3은 왼쪽 아래에서 오른쪽 위로 올라가는 모양이에요.
  • 식 전체에 -를 붙이면 그래프가 위아래로 뒤집혀요.
  • 식의 부호를 하나씩 바꿔 가며 위 실험실에서 모양이 어떻게 달라지는지 직접 비교해 보세요.
  • 판단이 어려울 땐 x = 0, x = 1 같은 쉬운 값을 넣어 y를 계산해 그래프의 점과 맞춰 보세요.

4-4. matplotlib 함수 정리

코드하는 일
plt.plot(x, y)선 그래프
plt.scatter(x, y)점으로 찍는 산점도 (두 값의 관계를 볼 때)
plt.boxplot([데이터1, 데이터2])상자 그림 (분포·중앙값·이상치)

plt.axhline(값, c="orange", linestyle="--")y = 값 위치에 가로선 (예: 평균선). c는 색, linestyle은 선 모양

plt.show()그래프 화면에 출력
코드

any(axis=1): 행마다(가로 방향으로) 하나라도 결측치가 있으면 True → 결측치가 있는 행만 골라내요.

결측치가 있는 행을 지울 때는 dropna()를 써요. 원본에 반영되는지가 핵심이에요.

코드
temp = df.copy()        # 연습용 복사본
temp.dropna()           # 지운 결과를 보여 주기만 함
print(len(temp))

temp.dropna(inplace=True)   # 원본(temp)에 바로 반영
print(len(temp))
실행 결과
12
10
코드원본이 바뀌나요?
df.dropna()❌ 결과를 보여 주기만 해요
df.dropna(inplace=False)❌ 기본값과 같아요
df.dropna(inplace=True)✅ 원본에서 바로 지워요
df = df.dropna()✅ 지운 결과를 다시 df에 저장해요

🔑 반복 횟수 계산하기
  • len(arr) = 4 (날짜 포함)이고, 숫자 열은 3개예요.
  • 방법 ②에서 range(len(arr))로 4번 돌리면 마지막에 arr[4]를 찾다가 오류(IndexError)가 나요.
  • 반복문 코드를 볼 때는 i에 0, 1, 2, …를 직접 넣어 보며 어떤 열이 나오는지 표로 써 보세요.
